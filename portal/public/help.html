Need a hand?

This preview is for testing the portal flow. Payments and Wi-Fi access are not enabled.

Can I buy a plan or get online here?

Not in this development preview. Choosing a plan can only create an unpaid test order; it does not send a mobile-money request, charge you, or activate Wi-Fi. Contact the compound owner directly if you need internet access.

What happens if I submit a test order?

The portal saves a pending development record only. You can look it up on the status page using its order reference and the same device address. No payment or subscription is created.

Will I receive a payment prompt?

No. The payment provider is not connected in this version, so no payment prompt is sent. Do not send money based on a test order.

Why does checkout need a device address?

The test order is associated with the device address supplied by the Wi-Fi portal. Without a router supplying that address, checkout stays disabled.

When will real payments and Wi-Fi access be available?

Only after the owner configures and tests the payment provider and MikroTik router. Until then, this website is a development preview and cannot provide internet access or process refunds.
